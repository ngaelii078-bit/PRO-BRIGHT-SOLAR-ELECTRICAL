# Pro Bright Solar & Electrical — HTML demo

Open `dist/index.html` directly in a browser. No installation or build is needed.

The responsive demo includes services, home/business solutions, FAQs, an enquiry form, a floating WhatsApp control, and a clearly labelled scripted assistant. The assistant is not live AI. No messages or form data are sent automatically or stored.

WhatsApp is configured for the user-supplied client number 082 763 8437 (+27 82 763 8437). To change it, edit `BUSINESS.whatsapp` in `dist/app.js`, using country code and digits only.

Google Fonts and illustrative Unsplash photos require internet. The photos are not presented as client installations. Business service references: https://take.app/probrightsolarandelectrical and Rustenburg Procompare listings. No unverified prices, testimonials or performance statistics are used.
